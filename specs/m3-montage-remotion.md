# M3 — монтаж через Remotion, озвучка, пословные субтитры и QC-агент монтажа

Статус: **готово** (01.11.2026): монтаж live #1 собран Remotion, QC пройден дважды подряд.

## Цель
Монтаж уровня ручного проекта `remotion_bs`, но собранный агентами: озвучка подписей, тайминг каждого слова,
подсветка слова в субтитрах, движение на статичных кадрах. Готовый ролик проверяет агент контроля качества
по чек-листу монтажа — тот же, по которому я проверяю ролики руками перед показом.

## Конвейер
1. **Озвучка** (`factory/voice.py`): подписи шотов → Piper TTS (локально, бесплатно) → wav на шот.
2. **Тайминг слов**: faster-whisper (локально) даёт тайминги; текст на экране берётся **из сценария**,
   а не из распознавания (автоматическая правка ослышек: «которые» → «которое»). Сопоставление — по последовательности слов.
3. **Фразы**: 2–4 слова, без служебного слова на конце, без висящего последнего слова (правила `subs_bs.py`).
4. **Remotion** (`remotion/`): ролик или кадр шота, на кадрах — медленный наезд камеры (нет стоп-кадров);
   субтитры Montserrat 900 капсом, текущее слово подсвечено; аудио — озвучка.
5. **QC-агент** (`factory/agents/qc.py`) проверяет готовый mp4 и пишет `qc.json` и событие в журнал.

## Критерии приёмки
| # | Критерий | Проверка |
|---|----------|----------|
| 1 | Выравнивание сценария по словам Whisper: ослышка заменяется словом сценария, тайминг сохраняется; пропущенное слово получает интерполированное время | `TestVoice.test_align_fixes_mishearing` |
| 2 | Фразы субтитров: ≤ 4 слов, не заканчиваются служебным словом | `TestVoice.test_phrases` |
| 3 | QC: чёрные кадры > 0,2 с — провал | `TestQC.test_black_detected` |
| 4 | QC: стоп-кадр > 1,0 с — провал | `TestQC.test_freeze_detected` |
| 5 | QC: «субтитры = звук» — WER распознанного звука ролика против сценария ≤ 15 % | `TestQC.test_wer` |
| 6 | QC: рассинхрон — начало слова в субтитрах против распознанного в готовом ролике ≤ 0,3 с (медиана) | live-прогон |
| 7 | QC: длительность ролика совпадает с таймлайном (±0,2 с), звук есть | live-прогон |
| 8 | Один слой текста: в монтаж идут ролики и чистые кадры, не карточки | `test_montage_uses_clean_frames_not_cards` |
| 9 | Монтаж live #1 собран Remotion из оплаченного материала без новых трат, QC пройден | `results/live-runs.md` |
| 10 | Фраза субтитров не переходит через склейку (найдено глазами, добавлено в QC) | `TestQC.test_phrase_across_cut_fails` |
| 11 | Озвучка — цикл дублей: синтез → распознавание → пересинтез (Piper недетерминирован) | событие `voice` с WER дублей |
| 12 | Произношение латиницы для синтеза (`brand.say`, `say:`), субтитры как в сценарии | live #1: «AURA» |
