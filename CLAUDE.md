# agent-factory — правила для Claude Code

- Работа идёт от спецификаций: новая фича = файл в `specs/` с критериями приёмки → тесты → код. Не писать код без спецификации.
- Тесты: `python3 -m unittest -v`. Все должны проходить до коммита.
- **Деньги.** Ничего не запускать с `--mode live` и не вызывать платные API (WaveSpeed, RunningHub) без явного «да» пользователя
  с суммой. Сначала `python3 -m factory plan <бриф>` и показать вилку стоимости.
- Ключи только из окружения или `~/.config/...`; никогда не печатать, не логировать, не коммитить.
- Выученные правила — в `memory/rules.yaml`, их коммитим: это знание фабрики. Результаты прогонов (`runs/`) не коммитим.
- После прогона показывать пользователю `report.md` и `factory stats`, а не пересказ.
- Субтитры и монтаж — по чек-листу: без обрывов фраз, без висящих служебных слов, один слой текста.
